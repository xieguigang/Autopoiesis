# 模拟算法的数学原理详解
这套脚本实现的本质上是一个 **二维环面上的非互易多体耗散动力系统**（Particle Life 模型）。每帧执行一次**同步更新**：所有粒子读取上一时刻的完整状态快照，计算受力并积分出新状态。所有数学核心都在 `compute.glsl` 中，可以拆成下面几个模块。
---
## 0. 状态空间与更新框架
每个粒子 $i$ 的状态为：
- 位置 $x_i \in [0, L_x) \times [0, L_y)$（$L = 2560 \times 1440$）
- 速度 $v_i \in \mathbb{R}^2$
- 类型 $t_i \in \{0, ..., T-1\}$，$T \le 10$
帧更新是一个显式映射：$(x, v)^{t+1} = \Phi\big[(x,v)^t\big]$。
代码里两个看似"工程实现"的设计其实都是数学正确性的保障：
- **双缓冲乒乓**（uniform_set_a/b 交替）：保证所有线程读到的是同一份完整旧状态，结果与线程调度顺序无关；
- **两遍循环**：密度必须先于力求值。若合并成一遍，每个线程在算力时密度还没累加完，早处理的邻居和晚处理的邻居会看到不同的密度值——更新就不再是对旧状态的纯函数。
---
## 1. 环面距离：最小像约定
世界是环形的，距离采用 **minimum image convention**：
```
wrap(v) = v - L · round(v / L)        （逐分量）
δ_ij = wrap(x_i - x_j)
d_ij = |δ_ij|
```
`round` 把位移折算到 $[-L/2, L/2]$ 区间，即任意一对粒子取的永远是**环面上最短路径**的距离。这使整个力场自动具备平移不变性和环绕连续性——跨越边界的两颗粒子照常相互作用，无需特殊处理。
---
## 2. 交互矩阵：故意打破牛顿第三定律
力矩阵 $F \in [-1, 1]^{T \times T}$，索引方式 `forces[type_a + type_b * T]`，即 $A_{ij} = F[t_i][t_j]$ 表示"**i 被 j 吸引的程度**"。
关键点：矩阵一般**不对称**（$A_{ij} \neq A_{ji}$），作用力与反作用力不相等 → 动量不守恒 → 系统不是哈密顿系统。这正是 Particle Life 能涌现出"追逃、细胞分裂、自复制"等行为的数学根源。再叠加后面的阻尼（耗散项），系统最终不是落入热平衡，而是落入**准稳态的自组织斑图**——这是非互易活跃物质系统的典型特征。
---
## 3. 密度场（第一遍循环）：核密度估计
```
ρ_i = Σ_{j≠i, d_ij<R} k(d_ij) · c(t_i, t_j)
k(d) = 1 - d/R          （线性衰减核）
c    = 1 （同类型） / 0.5 （异类型）
```
这本质上是一次**核密度估计（KDE）**：半径 $R$ 邻域内邻居的加权计数。同类型权重加倍，意味着"同类拥挤"的自抑制效应比异类更强——这直接影响了后面团簇的最大堆积密度，也造就了不同"物种"之间的不对等生态动力学。
---
## 4. 逐对力（第二遍循环）：分段线性力廓形
**第一步：密度抑制（只作用于吸引部分）**
```
φ(ρ) = 1 - clamp(ρ - ρ_limit, 0, 1.005)     ∈ [-0.005, 1]
A'   = A · φ                                （仅当 A > 0 时）
```
- $\rho \le \rho_{limit}$：$\varphi = 1$，不抑制；
- 超过密度上限后吸引力**线性衰减**，极端拥挤时甚至略微变负（轻微排斥）。
数学效果上相当于一个软"不可压缩"约束：吸引力随密度饱和，团簇无法无限坍缩——类似逻辑增长项的作用。注意排斥交互不受密度调制。
**第二步：力廓形函数**（$r$ = repulsion_radius，$R$ = interaction_radius，$m = \frac{r+R}{2}$，$W = R - r$）：
| 距离区间 | 力 $f(d)$ | 含义 |
|---|---|---|
| $d < r$ | $2(d/r - 1) \in [-2, 0)$ | 硬核排斥，恒为负，斜率 $2/r$ |
| $r \le d \le R$ | $A' \cdot \left(1 - \frac{\lvert d - m \rvert}{W/2}\right)$ | 以 $m$ 为峰的**三角形吸引核**，峰值 $= A'$，两端为零 |
| $d > R$ | $0$ | 无交互 |
这是经典 Particle Life 力函数的变体：短程硬排斥防止粒子重叠坍缩，中程三角形吸引构成一个**势阱**（线性力 ↔ 分段二次势能，阱底在 $m$ 处，深度 $\propto A' \cdot W$）。粒子会稳定停留在势阱底部而非贴在一起——这是团簇能保持"细胞状"结构的关键。
**第三步：矢量叠加**
$$F_i = \sum_j n_{ij} \cdot f(d_{ij}) \cdot (-50), \qquad n_{ij} = \frac{\delta_{ij}}{d_{ij}}$$
方向约定：$n_{ij}$ 从邻居 $j$ 指向 $i$。因此：
- $f < 0$（排斥区）→ $-50f > 0$ → 力沿 $n$ 方向 → **推离** $j$；
- $f > 0$（吸引区）→ 力与 $n$ 反向 → **拉向** $j$。
系数 $-50$ 是全局刚度/时间尺度常数。
---
## 5. 退化情形与数值限幅
**① $d = 0$ 完全重合**：距离公式分母为零，此时注入确定性伪随机抖动：
```
random(v) = fract(sin(dot(v, (12.9898, 78.233))) · 43758.5453)
```
这是经典的 GLSL sin-hash。作用是**对称性破缺**：两颗粒子完全重合时若无扰动，受力将永远为零、永久锁死；以粒子索引 + 坐标作自变量保证扰动互不相关。
**② 力截断**：$\lvert F_i \rvert > 100$ 时归一化到 100。注意一个精巧的巧合：单对粒子最大排斥力 = $2 \times 50 = 100$，恰好等于截断值——所以限幅实际只约束**多邻居合力叠加**的情形，防止密集区域合力爆炸。
---
## 6. 时间积分：半隐式欧拉 + 线性阻尼
```
v ← β · (v + F·Δt)         β = dampening（默认 0.85）
x ← x + v·Δt
x ← mod(x + L, L)          环面回绕，保持与第 1 节度量自洽
```
- **半隐式（辛）欧拉**：先更新速度、再用新速度更新位置，比显式欧拉稳定得多（对振荡系统允许更大的步长）；
- **乘法阻尼**等效于摩擦力。恒力作用下的终末速度为有限值：
$$v^* = \frac{\beta}{1-\beta} F \Delta t$$
即系统必然耗散收敛，不会持续注入能量。$\beta = 0.85$ 时速度每约 4 帧减半。
- CPU 侧 $\Delta t = 5 \times$ 帧间隔（60 FPS 时 ≈ 0.083）。
**稳定性直觉**：单步最大速度增量 $\le 100 \times 0.083 \approx 8.3$ px，终末速度有界，且排斥半径（默认 20）大于单步最大位移——穿透和数值爆炸基本被排除。**力限幅 + 阻尼 + 硬核排斥**三者共同构成稳定性三重保险。
---
## 7. 渲染的数学（step = 1）
- **视图变换**：`delta = mod(pos + camera_origin + center + r, region) - center` —— 用 mod 实现环面无缝回绕：粒子滑出一侧即从另一侧重现，配合 origin 实现环面上的无限平移相机；
- **缩放**：像素半径 $r_{px} = r \cdot zoom$，坐标乘 zoom 后超出纹理的写入被丢弃 → zoom > 1 时自然呈现"视口缩小看局部"；
- **圆盘光栅化**：`range = ⌈r·zoom⌉`，遍历 $(2 \cdot range + 1)^2$ 包围盒，判定
$$\lvert p + 0.5 - s \rvert < r_{px} \implies \text{imageStore}(color)$$
其中 $+0.5$ 是标准像素中心约定。每个粒子独立画实心圆、无深度/混合，重叠处后写覆盖（颜色不透明所以视觉无差异）。
---
## 8. 复杂度与并行化
| 阶段 | 复杂度 | 并行方式 |
|---|---|---|
| 物理（两遍） | $O(N^2)$ | 每线程一个粒子，$\lceil N/256 \rceil$ 个工作组 |
| 渲染 | $O(N \cdot (2r+1)^2)$ | 每线程画自己的圆盘 |
滑杆上限 317² ≈ **10 万粒子**，意味着每帧约 $10^{10}$ 次粒子对交互——只有全 GPU 暴力并行才可能实时。着色器开头的 `if (i >= particle_count) return;` 使工作组的整除溢出无害。
---
## 总结：一个公式看全貌
整个模拟就是不断迭代这个离散动力系统：
$$\begin{cases} \rho_i = \sum_j k(d_{ij})\, c_{ij} & \text{（核密度估计）}\\[4pt] F_i = -50 \sum_j n_{ij}\, f\big(d_{ij};\, A'_{ij}, \varphi(\rho_i)\big), \quad \lvert F_i \rvert \le 100 & \text{（非互易分段线性力场）}\\[4pt] v_i \leftarrow \beta(v_i + F_i \Delta t), \quad x_i \leftarrow \mathrm{mod}(x_i + v_i \Delta t, L) & \text{（阻尼辛欧拉 + 环面回绕）} \end{cases}$$
**非互易力矩阵提供驱动力和模式多样性，密度抑制提供饱和/不可压缩性，阻尼提供耗散收敛，环面拓扑消除边界效应**——四者结合，使系统在远离平衡态处稳定地维持出自发的"细胞"斑图。这就是该算法在数学上最精妙的地方：它不是在解一个守恒的物理系统，而是在构造一个精心设计的耗散动力系统，让目标结构成为系统的吸引子。
